# Yousri Ben Hariz

My personal CV website: cybersecurity student, CTF player, robotics and AI builder.

**Live:** https://yousri25.github.io

## About

A single-page site with a Kali Linux terminal theme. Pages: Accueil (projects), Parcours, Distinctions, Compétences, Whoami. The site is in French.

## Built with

- HTML, CSS and vanilla JavaScript
- No framework, no build step, one file: `index.html`
- Dark and light themes

## Run locally

Open `index.html` in your browser.
